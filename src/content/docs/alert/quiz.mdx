    explanation="4688 does have a CommandLine field, but populating it requires the Group Policy setting 'Include command line in process creation events' (Computer Configuration > Administrative Templates > System > Audit Process Creation), which is off by default, on top of the Audit Process Creation audit policy that makes 4688 fire at all.
