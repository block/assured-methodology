    options={[
      { value: "size", label: "Triage is small cases; IR is big cases." },

      { value: "question", label: "Triage frames the puzzle ('what is this?'). IR completes it ('how do we stop it?'). Different questions, different mindsets, different outputs." },

    ]}
    answer="question"
    explanation="The distinction is about the question being asked. Triage is 'what is going on.' IR is 'what do we do about it.' Conflating them leads to premature escalation or stalled investigations."

  <QuizItem
    prompt="The handoff packet should be optimized for..."
    options={[
      { value: "brevity", label: "Brevity. Keep it short." },

      { value: "compliance", label: "Compliance reporting." },
      { value: "manager", label: "The SOC manager's review." },
    ]}
    answer="completeness"
    explanation="The packet is the bridge between triage and IR. The metric is whether the next tier can act without asking the triage analyst to re-explain. Brevity is good; completeness is the goal."
  />
