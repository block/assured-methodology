      <h3>Persistence</h3>
      <p>Why removing the malware is rarely enough. Mature adversaries plant multiple anchors (registry Run keys, scheduled tasks, services, WMI event subscriptions) so reboots, password resets, and even partial cleanups leave at least one foothold intact. Defenders need to enumerate every place persistence might hide before they can call a host clean.</p>

      <p>Windows User Account Control should prompt before elevation. Bypass techniques (abusing auto-elevating binaries like <code>fodhelper.exe</code>, <code>eventvwr.exe</code>, or registry hijacks) skip the prompt entirely. The dialog never fires and the privilege escalation succeeds silently.</p>

  {/* Term grid */}
  <div class="bad-terms">
    <article class="bad-term"><h4>Advanced Persistent Threat (APT)</h4><p>A prolonged, covert cyberattack by a skilled adversary, often state-sponsored, that gains and maintains unauthorized access to a network.</p></article>
    <article class="bad-term"><h4>COM Hijacking</h4><p>A persistence technique that abuses Windows Component Object Model (COM) registry entries to hijack the execution flow of legitimate applications.</p></article>
    <article class="bad-term"><h4>Compromised Host</h4><p>A system under attacker control, often used for lateral movement, staging malware, or maintaining persistence within a network.</p></article>
    <article class="bad-term"><h4>Defense Evasion</h4><p>Techniques used to avoid detection and interference from security tools, including obfuscation, disabling defenses, and mimicking legitimate activity.</p></article>
    <article class="bad-term"><h4>Escape-The-Box</h4><p>An attack that breaks out of a restricted environment (container, VM, sandbox) to gain access to the underlying host system.</p></article>
    <article class="bad-term"><h4>Execution</h4><p>The attacker successfully runs malicious code on a system, typically using interpreters, scripts, payloads, or legitimate tools.</p></article>
    <article class="bad-term"><h4>Initial Access</h4><p>The first step of a breach, where attackers gain a foothold in the environment through phishing, exploits, credential abuse, or exposed services.</p></article>
    <article class="bad-term"><h4>Insider Risk</h4><p>Risk of harm originating from a person with authorized access, typically through negligence, mistake, or policy violation rather than deliberate intent. Distinct from <em>insider threat</em>, which is deliberate.</p></article>
    <article class="bad-term"><h4>Insider Threat</h4><p>A trusted internal user who intentionally abuses their access to cause harm, steal data, or assist external attackers.</p></article>
    <article class="bad-term"><h4>Jailbreaking</h4><p>The removal of OS-level security restrictions, particularly on iOS devices, to allow unauthorized control, often used maliciously.</p></article>
    <article class="bad-term bad-term--featured"><h4>Lateral Movement</h4><p>An attacker's method of traversing a network to escalate access, find sensitive data, or reach higher-value targets.</p></article>
    <article class="bad-term"><h4>Logic Attack</h4><p>A technique that exploits flaws in system logic or workflows, rather than code, to bypass controls or cause disruption.</p></article>
    <article class="bad-term"><h4>Malware</h4><p>Software designed to disrupt, damage, or gain unauthorized access to systems. Encompasses ransomware, trojans, worms, viruses, spyware, wipers, rootkits, and the other malware families catalogued below.</p></article>
    <article class="bad-term"><h4>Payload Deployment</h4><p>The delivery and installation of malicious software, tools, or scripts intended to perform an attacker's objectives.</p></article>
    <article class="bad-term bad-term--featured"><h4>Persistence</h4><p>Tactics that maintain access across reboots, updates, or password changes. Multiple anchors, Run keys, scheduled tasks, services, WMI event subs.</p></article>
    <article class="bad-term"><h4>Post-Exploitation</h4><p>The phase where the attacker explores the environment, escalates access, exfiltrates data, or sets up long-term control.</p></article>
    <article class="bad-term"><h4>Pre-Exploitation</h4><p>The reconnaissance and scanning phase, where attackers gather intelligence and identify vulnerabilities before launching an attack.</p></article>
    <article class="bad-term"><h4>Privilege Chaining</h4><p>The sequential use of multiple smaller privilege escalations or credential compromises to progressively gain more powerful access.</p></article>
    <article class="bad-term bad-term--featured"><h4>Privilege Escalation</h4><p>The act of increasing privileges on a system. Standard user → admin → SYSTEM → domain admin.</p></article>
    <article class="bad-term"><h4>Remote Execution</h4><p>Running commands or malicious code on a target system from a remote location, often via exploits or administrative tools.</p></article>
    <article class="bad-term bad-term--featured"><h4>SQL Injection</h4><p>Code injection where malicious SQL is inserted into input fields to manipulate backend databases.</p></article>
    <article class="bad-term"><h4>Staged Payloads</h4><p>A two-phase delivery process where a lightweight stager downloads and executes a more complex secondary payload.</p></article>
    <article class="bad-term"><h4>System Tampering</h4><p>The unauthorized modification of system configurations, binaries, or behaviors to support attacker goals or disrupt operations.</p></article>
    <article class="bad-term bad-term--featured"><h4>UAC Bypass</h4><p>Circumventing Windows User Account Control prompts to gain elevated privileges without user approval.</p></article>
    <article class="bad-term bad-term--featured"><h4>Zero Day</h4><p>A previously unknown vulnerability with no patch, exploited before the vendor can respond.</p></article>
  </div>

    <div>
      <h2>Threat actor profiles</h2>
      <p>Named groups and individuals known for malicious cyber activity. Their tradecraft, motivations, and historical campaigns shape modern triage.</p>
    </div>
  </header>

  <div class="bad-actors">
    <article class="bad-actor" data-origin="🇨🇳"><h4>APT10 <span>Cloud Hopper</span></h4><p>Chinese state-sponsored group associated with global IP theft. Their Cloud Hopper campaign targeted managed service providers (MSPs) to compromise downstream customers. Focus: healthcare, defense, aerospace, tech. Uses RedLeaves, custom loaders, spear-phishing, credential theft, and cloud-service abuse aligned with China's economic and military goals.</p></article>
    <article class="bad-actor" data-origin="🇷🇺"><h4>APT28 <span>Fancy Bear / GRU</span></h4><p>Linked to Russia's GRU and known for aggressive operations. Credential harvesting, malware deployment, destructive attacks against political and military targets. Tied to the 2016 DNC breach and many NATO-related campaigns. Leverages zero-days and weaponized Office documents. Noisier and more direct than APT29; a primary actor in Russian hybrid warfare.</p></article>
    <article class="bad-actor" data-origin="🇷🇺"><h4>APT29 <span>Cozy Bear / SVR</span></h4><p>Sophisticated espionage group associated with Russia's SVR. Stealth and long-term access. Targets governments, think tanks, healthcare, vaccine researchers. One of the groups behind SolarWinds (UNC2452). Custom malware, living-off-the-land, well-crafted spear-phishing. Operations often go undetected for months. Modular tooling, adaptive infrastructure.</p></article>
    <article class="bad-actor" data-origin="🇮🇷"><h4>APT33 <span>Iran / aviation + energy</span></h4><p>Iranian government-linked group targeting aerospace, energy, and critical infrastructure. Mixes espionage with destructive operations including Shamoon wiper variants. Phishing campaigns tied to fake aviation job postings. Represents Iran's evolving cyber capability and willingness to engage in hybrid warfare.</p></article>
    <article class="bad-actor" data-origin="🇮🇷"><h4>Charming Kitten <span>APT35 / Phosphorus</span></h4><p>Iranian group conducting espionage against academics, human rights activists, and government entities. Phishing, fake social personas, credential harvesting. Known for impersonating journalists and think tanks. Supports Iran's strategic interests in surveillance and foreign intelligence collection. Active for over a decade.</p></article>
    <article class="bad-actor" data-origin="👤"><h4>Edward Snowden <span>insider disclosure</span></h4><p>Former NSA contractor who leaked classified documents revealing global surveillance programs. Not a traditional threat actor, but his disclosures had massive impact on public awareness, policy, and cybersecurity posture. Viewed variously as a whistleblower, a leaker, or a traitor. A touchpoint for discussions on data access, civil liberties, and operational secrecy.</p></article>
    <article class="bad-actor" data-origin="🇷🇺"><h4>Evil Corp <span>Dridex / WastedLocker</span></h4><p>Russian cybercrime group behind the Dridex banking trojan and BitPaymer / WastedLocker ransomware. Hundreds of millions stolen from global financial institutions. U.S. Treasury has sanctioned the group and its alleged leader Maksim Yakubets. Has continued operations under new malware names to evade sanctions and tracking.</p></article>
    <article class="bad-actor" data-origin="💰"><h4>FIN7 <span>Carbanak / Bateleur</span></h4><p>Well-organized cybercrime group conducting large-scale intrusions against banks, POS systems, and hospitality. Has rebranded after arrests, including via fronts like Combi Security.</p></article>
    <article class="bad-actor" data-origin="🇨🇳"><h4>HAFNIUM <span>Exchange zero-days</span></h4><p>Suspected Chinese state-sponsored group, widely known for exploiting Microsoft Exchange zero-days in 2021. Web-shell deployment and widespread data theft from education, law firms, NGOs, and defense contractors. Uses a mix of custom malware and commercial tools, including C2 over compromised Exchange servers.</p></article>
    <article class="bad-actor" data-origin="💥"><h4>LAPSUS$ <span>Okta, Microsoft, Nvidia</span></h4><p>Loosely organized group known for extortion, data leaks, and high-profile breaches. Access via SIM-swapping, credential theft, and insider recruitment rather than malware. Thrives on media attention and public-facing leaks. Members believed to be primarily teenagers, with arrests in the UK. Disruption over stealth.</p></article>
    <article class="bad-actor" data-origin="🇰🇵"><h4>Lazarus Group <span>North Korea / RGB</span></h4><p>Umbrella term for several North Korean operations under the Reconnaissance General Bureau. Espionage, sabotage, and financially motivated attacks: Sony Pictures, WannaCry, bank and crypto-exchange theft. Blends APT tradecraft with cybercrime to fund the regime. Strategic patience plus opportunistic targeting.</p></article>
    <article class="bad-actor" data-origin="🇷🇺"><h4>Sandworm <span>GRU / destructive ops</span></h4><p>Destructive GRU unit behind the 2015 / 2016 Ukraine power grid attacks (BlackEnergy, Industroyer) and the global NotPetya wiper. Tools include VPNFilter, KillDisk, Cyclops Blink. Specializes in ICS/OT disruption, hybrid warfare, and psychological operations. Aligned with Russian military objectives.</p></article>
    <article class="bad-actor" data-origin="🇳🇬"><h4>SilverTerrier <span>Nigerian BEC</span></h4><p>Collective term for Nigerian actors conducting Business Email Compromise fraud. Hundreds of arrests, but the group continues to evolve.</p></article>
    <article class="bad-actor" data-origin="💸"><h4>TA505 <span>large-scale malware ops</span></h4><p>Prolific cybercriminal group distributing banking trojans, ransomware, and RATs globally. Frequent massive phishing waves delivering Dridex, FlawedAmmyy, Locky. Often acts as an initial-access broker for other groups. Frequently shifts tactics, payloads, and infrastructure. Exemplifies the malware-as-a-service model.</p></article>
    <article class="bad-actor" data-origin="🇷🇺"><h4>Turla <span>FSB / long-running espionage</span></h4><p>Long-running Russian cyber-espionage group linked to the FSB. Targets governments, embassies, militaries. Custom implants like Snake, Carbon, Kazuar. Hijacks infrastructure from other malware families to obfuscate attribution. Watering holes, poisoned updates, compromised email systems. Tradecraft emphasizes longevity and covertness.</p></article>
    <article class="bad-actor" data-origin="🛰️"><h4>UNC2452 <span>Mandiant / SolarWinds</span></h4><p>Mandiant designation for the threat group behind the SolarWinds supply-chain compromise, later linked to APT29. Introduced the SUNBURST backdoor into Orion updates, affecting U.S. government agencies and Fortune 500 companies. Stealthy lateral movement and privilege escalation. Undetected for months. A landmark case for software trust chains.</p></article>
    <article class="bad-actor" data-origin="💰"><h4>Wizard Spider <span>Ryuk / Conti / TrickBot</span></h4><p>Russia-based cybercriminal group behind Ryuk, Conti, and TrickBot. Financially motivated; hundreds of millions extorted from hospitals, municipalities, corporations. Operates within a larger ecosystem of IABs and malware developers. Fast lateral movement, data theft, double extortion. Often preceded by TrickBot or BazarLoader infections.</p></article>

    <article class="bad-campaign" data-year="2016"><h4>Cambridge Analytica</h4><p>Political consulting firm that improperly harvested data from 87 million Facebook users. Not a traditional cyberattack, but exposed serious flaws in data privacy and third-party app oversight. Triggered global debate about surveillance capitalism and election interference; GDPR enforcement followed.</p></article>
    <article class="bad-campaign" data-year="2017"><h4>Cloud Hopper</h4><p>Widespread espionage campaign by China's APT10 targeting MSPs globally. Resulted in a historic $700M settlement and regulatory reforms focused on data protection.</p></article>
    <article class="bad-campaign" data-year="2021"><h4>Log4Shell</h4><p>CVE-2021-44228, a critical RCE in Apache Log4j. Attacker-controlled input is interpolated into a log message that triggers a JNDI lookup, which loads and executes a remote class. Disclosed December 2021, exploited globally within hours. Affected vast swaths of Java applications. Renewed calls for software bill-of-materials and open-source security funding. Reset assumptions about transitive-dependency risk.</p></article>
    <article class="bad-campaign" data-year="2021"><h4>HAFNIUM Exchange</h4><p>Early 2021 chain of zero-day exploits in Microsoft Exchange Server.     <article class="bad-campaign" data-year="2017"><h4>NotPetya</h4><p>Destructive cyberattack masquerading as ransomware, attributed to Russia's GRU Sandworm. Billions in damages and a defining case study in supply-chain abuse.</p></article>
    <article class="bad-campaign" data-year="2010"><h4>Operation Aurora</h4><p>2009–2010 China-attributed intrusions targeting Google, Adobe, and dozens of others. Zero-day in Internet Explorer used to deploy backdoors and steal source code and IP. Google's public disclosure was a turning point in public discussion of state-sponsored industrial espionage and APTs.</p></article>
    <article class="bad-campaign" data-year="2019"><h4>Operation ShadowHammer</h4><p>2019 supply-chain compromise of the ASUS software update utility. Compromised updates were signed and shipped from ASUS's own servers, reaching hundreds of thousands. Payload activated only on specific targets, suggesting selective espionage. Stolen certificates plus supply-chain trust. Linked to nation-state-capable APT activity.</p></article>
    <article class="bad-campaign" data-year="2015"><h4>OPM breach</h4><p>2015 breach compromising SF-86 background investigation records (and fingerprints) for 21+ million U.S. federal personnel. Attributed to Chinese state-sponsored actors. A goldmine for counterintelligence. Major reforms in U.S. government cybersecurity practices and incident response readiness followed.</p></article>
    <article class="bad-campaign" data-year="2014"><h4>Sony Pictures hack</h4><p>2014 destructive attack attributed to North Korea's Lazarus Group, reportedly in retaliation for The Interview. Wiper malware, leaked unreleased films, and exposed executive communications. Blended political retaliation, information warfare, and corporate sabotage. First high-profile nation-state attack on a private company over content.</p></article>
    <article class="bad-campaign" data-year="2020"><h4>SolarWinds SUNBURST</h4><p>Late-2020 supply-chain compromise of SolarWinds Orion. Trojanized update gave APT29 / UNC2452 backdoor access to thousands of customers including U.S. government agencies and Fortune 500 firms. Stealthy command-and-control, lateral movement, and data exfiltration over months. Reshaped trust assumptions around software vendors.</p></article>
    <article class="bad-campaign" data-year="2010"><h4>Stuxnet</h4><p>Landmark cyberweapon developed jointly by the U.S. and Israel to disrupt Iran's nuclear enrichment. Multiple zero-days and PLC-specific payloads targeted Siemens controllers at Natanz. Altered centrifuge speeds while reporting normal readings. First malware known to cause real-world industrial damage. Inspired subsequent ICS-targeting malware.</p></article>
    <article class="bad-campaign" data-year="2013"><h4>Target breach</h4><p>2013 breach compromising payment data for 40 million customers and PII for 70 million more. Initial access via a compromised HVAC contractor; lateral movement to POS systems; malware on registers captured card data. A landmark for third-party risk management and network segmentation. Hundreds of millions in costs and executive resignations.</p></article>
    <article class="bad-campaign" data-year="2015"><h4>Ukraine power grid</h4><p>2015 and 2016 attacks marking the first known successful cyberattacks to cause power outages. Attributed to Russia's Sandworm. Spear-phishing plus BlackEnergy to gain SCADA access; operators locked out as breakers were opened manually. 2016 used Industroyer / CrashOverride targeting grid-specific protocols. Defining examples of cyber warfare against civilian infrastructure.</p></article>
    <article class="bad-campaign" data-year="2017"><h4>WannaCry</h4><p>May 2017 ransomware outbreak using EternalBlue (NSA SMB exploit leaked by Shadow Brokers). Wormed across networks, encrypting files in 150+ countries; the UK NHS was hit hard. Microsoft had released the patch beforehand, but many systems were unpatched. Attributed to North Korea's Lazarus Group. A wake-up call on patch hygiene.</p></article>
    <article class="bad-campaign" data-year="2023"><h4>Storm-0558 (Microsoft cloud email)</h4><p>July 2023 intrusion in which a China-aligned actor forged Azure AD access tokens using a stolen Microsoft consumer-MSA signing key, reading emails of ~25 organizations including U.S. State Department and Commerce officials via Outlook Web Access. The key should not have signed enterprise tokens; a validation gap let it. Reshaped how the industry talks about identity-provider key custody, token-binding, and the blast radius of a single signing key.</p></article>
    <article class="bad-campaign" data-year="2023"><h4>MOVEit Transfer mass exploitation</h4><p>May–June 2023 zero-day SQL-injection in Progress Software's MOVEit Transfer (CVE-2023-34362), exploited at scale by the Cl0p ransomware group. Thousands of organizations affected via the file-transfer vendor's customer base — U.S. federal agencies, state DMVs, Fortune 500 firms. A defining case for third-party-software risk and for ransomware groups shifting from encryption to pure data-extortion.</p></article>
    <article class="bad-campaign" data-year="2023"><h4>Okta support-system breach</h4><p>October 2023 intrusion of Okta's customer support case-management system. Attackers used a service-account credential found in a Google account session to access HAR files customers had uploaded for troubleshooting — HAR files that contained valid session cookies. Drove home that "support" surfaces handle production credentials and need the same identity-provider rigor as the products themselves.</p></article>
    <article class="bad-campaign" data-year="2024"><h4>XZ Utils backdoor</h4><p>March 2024. A multi-year social-engineering campaign by a fictitious maintainer ("Jia Tan") inserted a stealthy backdoor (CVE-2024-3094) into the xz/liblzma compression library that would have given remote SSH code execution on Linux systems linked against the affected build. Caught by chance by a Microsoft engineer noticing a 500ms slowdown. A defining open-source supply-chain case and the catalyst for renewed maintainer-trust scrutiny.</p></article>
    <article class="bad-campaign" data-year="2024"><h4>Snowflake customer-account theft</h4><p>April–June 2024. A threat group later tracked as UNC5537 used credentials harvested from infostealer logs to access Snowflake customer environments that had no MFA configured. Victims included Ticketmaster, Santander, AT&amp;T, LendingTree. Not a Snowflake CVE — a customer-side identity hygiene failure at scale. Drove the industry-wide push for MFA-mandatory cloud SaaS access.</p></article>
    <article class="bad-campaign" data-year="2024"><h4>Volt Typhoon / Salt Typhoon</h4><p>2024 disclosures of two long-running China-linked campaigns against U.S. critical infrastructure. <strong>Volt Typhoon</strong> pre-positioned in energy, water, communications, and transportation networks using living-off-the-land techniques for stealthy persistence. <strong>Salt Typhoon</strong> compromised major U.S. telecom carriers' lawful-intercept systems with potential access to call metadata and the federal wiretap apparatus. Reframed the boundary between espionage and prepositioning for disruptive action.</p></article>

        <text x="160" y="185" text-anchor="middle" font-family="ui-monospace,monospace" font-size="10" fill="#ef4444">↑ irreversibly overwritten</text>
      </svg>
    </div>
    <div class="bad-feature__text">
      <span class="bad-feature__tag">FEATURED</span>
      <h3>Wiper Malware</h3>
      <p>The destructive cousin of ransomware. There is no decryption key, no negotiation, no recovery; wiper overwrites data structures so the disk cannot be restored. NotPetya, Shamoon, and WhisperGate all wore the ransom-note costume while quietly destroying the underlying data.</p>
    </div>
  </article>

  <div class="bad-terms">
    <article class="bad-term"><h4>Adware</h4><p>Malware that displays unwanted advertisements, often bundled with legitimate software. Advanced adware can harvest data or serve as a delivery mechanism for more serious malware.</p></article>
    <article class="bad-term"><h4>Backdoors</h4><p>Malicious code that provides unauthorized access to a compromised system, bypassing normal authentication. Often installed post-exploitation to maintain persistent remote control.</p></article>
    <article class="bad-term"><h4>Banker Trojans</h4><p>Malware designed to steal banking credentials and financial information by intercepting login sessions, injecting fake forms, or logging keystrokes. Often targets online banking and payment systems.</p></article>
    <article class="bad-term"><h4>Banking Droppers (Loaders)</h4><p>Lightweight malware designed solely to download and execute a more substantial payload, often a banking trojan or ransomware. Examples include Emotet, ZLoader, Smoke Loader.</p></article>
    <article class="bad-term"><h4>Bootkits</h4><p>Highly persistent malware that infects the bootloader or Master Boot Record to gain control before the OS loads. Difficult to detect or remove since they operate beneath the operating system.</p></article>
    <article class="bad-term bad-term--featured"><h4>Botnets</h4><p>A network of infected machines (bots) controlled by a central attacker, used for DDoS, spam, credential stuffing, and more.</p></article>
    <article class="bad-term"><h4>Click Fraud Malware</h4><p>Malware that simulates user clicks on advertisements to generate fraudulent revenue. Often run on compromised systems in large volumes to exploit pay-per-click ad platforms.</p></article>
    <article class="bad-term"><h4>Crypters / Packers</h4><p>Tooling that uses encryption or obfuscation to hide malicious code and evade antivirus. Not malicious on their own but commonly paired with trojans, RATs, or ransomware.</p></article>
    <article class="bad-term"><h4>Fileless Malware</h4><p>Malware that operates in memory without writing files to disk, harder to detect with traditional AV. Often leverages legitimate system tools like PowerShell or WMI for execution.</p></article>
    <article class="bad-term"><h4>Infostealers</h4><p>Software that harvests sensitive data from victims: passwords, cookies, browser history, autofill. Commonly used in initial-access phases of broader attack campaigns.</p></article>
    <article class="bad-term"><h4>IoT Malware</h4><p>Designed to infect Internet of Things devices like routers, cameras, smart appliances. Often used in botnets (e.g., Mirai) due to weak authentication and outdated firmware.</p></article>
    <article class="bad-term"><h4>Logic Bombs</h4><p>Malicious code triggered by specific conditions, such as a date or user action. Can remain dormant until activated, then execute destructive or stealthy functions.</p></article>
    <article class="bad-term"><h4>Mobile Malware</h4><p>Malware targeting mobile devices, often distributed via malicious apps or phishing links. Includes SMS stealers, fake banking apps, mobile RATs.</p></article>
    <article class="bad-term"><h4>Polymorphic Malware</h4><p>Malware that constantly changes its code or appearance to evade signature-based defenses. Underlying functionality remains the same despite changing forms.</p></article>
    <article class="bad-term bad-term--featured"><h4>Ransomware</h4><p>Malware that encrypts a victim's files and demands payment for the key. Modern ransomware often includes data theft and extortion.</p></article>
    <article class="bad-term"><h4>Remote Access Trojan (RAT)</h4><p>Malware that masquerades as legitimate software and, once installed, gives the operator interactive remote control of the host. The trojan delivery is load-bearing: the user runs it willingly. Common capabilities include keylogging, screen capture, file transfer, and webcam access.</p></article>
    <article class="bad-term"><h4>Rootkits</h4><p>Malware that hides its presence by subverting the OS or using kernel-level access. Often combined with other malware to maintain stealth and persistence.</p></article>
    <article class="bad-term"><h4>Scareware</h4><p>Software that tricks users into believing their device is infected, pressuring them to buy fake antivirus tools. Often a social-engineering precursor to real malware.</p></article>
    <article class="bad-term"><h4>Spyware</h4><p>Malware that secretly monitors user activity: keystrokes, screen captures, camera or microphone access. Used for surveillance, espionage, or credential theft.</p></article>
    <article class="bad-term bad-term--featured"><h4>Wiper Malware</h4><p>Malware designed to irreversibly delete data and destroy system functionality. NotPetya, Shamoon, WhisperGate.</p></article>
  </div>
</section>

<section id="families" class="bad-section">
  <header class="bad-section__head">
    <span class="bad-section__ico" aria-hidden="true">🦠</span>
    <div>
      <h2>Malware families</h2>
      <p>Named tools and campaign malware tied to specific actors or operations.</p>
    </div>
  </header>

  <div class="bad-families">
    <article class="bad-family"><h4>BlackCat / ALPHV</h4><p>Sophisticated ransomware-as-a-service operation, one of the first to use Rust, making detection and analysis harder. Highly customizable Windows / Linux payloads, double-extortion with leak-site shaming. Successor to BlackMatter / REvil. Aggressive targeting of critical infrastructure and high-profile enterprises.</p></article>
    <article class="bad-family"><h4>Cobalt Strike</h4><p>Legitimate post-exploitation tool widely abused for C2, lateral movement, and credential harvesting. Beaconing, fileless injection, encrypted comms. Pirated and cracked versions used by APTs, ransomware gangs, and commodity malware. Frequently paired with TrickBot or BazarLoader to coordinate ransomware deployment.</p></article>
    <article class="bad-family"><h4>Conti</h4><p>One of the most prolific ransomware groups before disbanding in 2022. Centralized structure, professional affiliate model, human-operated intrusions. Used Cobalt Strike and TrickBot for movement. Internal chat-log leaks in 2022 exposed structure, operations, and finances. Many former members moved to BlackCat or Royal.</p></article>
    <article class="bad-family"><h4>Dridex</h4><p>Banking Trojan evolved into a modular platform for credential theft, lateral movement, and ransomware delivery. Spread via Word macros; injects into browsers to harvest banking credentials. Used to deploy Locky and BitPaymer. Associated with Evil Corp. Still under active development despite arrests.</p></article>
    <article class="bad-family"><h4>EmPyre / Empire</h4><p>Open-source post-exploitation framework with Python-based agents (EmPyre is the macOS/Linux branch; Empire is the PowerShell/Windows branch). Originally a red-team tool, adopted by various actors. Encrypted C2, evasion techniques, in-memory execution. Less common in the wild than Cobalt Strike, but its presence in a compromise should be treated as a high-risk indicator. Not a backdoor.</p></article>
    <article class="bad-family"><h4>IcedID (BokBot)</h4><p>Banking Trojan turned loader frequently used to drop Cobalt Strike, TrickBot, or ransomware. Spread through malicious documents and phishing. Modular: credential theft, web injection, lateral movement. Persistence via scheduled tasks and registry keys. A key player in post-intrusion ransomware operations.</p></article>
    <article class="bad-family"><h4>Maze</h4><p>Pioneer of double extortion, encryption plus data theft to pressure victims. RaaS model with public leak blog. Exploited RDP, phishing, and known vulnerabilities; used Cobalt Strike and Mimikatz internally. Announced retirement in late 2020, but affiliates continued under banners like Egregor and Sekhmet.</p></article>
    <article class="bad-family"><h4>Qakbot (Qbot)</h4><p>Multifunctional banking Trojan and malware dropper that evolved into a full-featured loader. Email-thread hijacking for phishing. Persistence, network discovery, credential harvesting, encrypted C2. Cornerstone of many enterprise compromises. Coordinated international disruption in 2023, but variants may persist.</p></article>
    <article class="bad-family"><h4>RedLine</h4><p>Infostealer sold on underground forums. Harvests credentials, browser data, cryptocurrency wallets, and system information. Distributed via cracked software, malvertising, phishing, and fake installers. JSON-over-HTTP/S C2. Customizable and affordable; popular among low-skill actors and initial-access brokers.</p></article>
    <article class="bad-family"><h4>Ryuk</h4><p>High-impact ransomware operated by Wizard Spider, typically delivered via TrickBot or BazarLoader. AES/RSA file encryption. Targets hospitals, municipalities, critical infrastructure. Fast encryption, kills backup and recovery processes. Operators are believed to overlap heavily with the subsequent Conti operation, which is generally treated as the successor brand.</p></article>
    <article class="bad-family"><h4>Shamoon</h4><p>Destructive wiper associated with Iranian state-sponsored actors. Infamous for the 2012 and 2016 attacks on Saudi Aramco. Overwrites MBR with provocative imagery, renders devices inoperable. Spreads via stolen credentials and admin shares. Primary goal is destruction, not financial gain.</p></article>
    <article class="bad-family"><h4>TrickBot</h4><p>Began as a banking Trojan, evolved into a modular enterprise-scale framework. Credential theft, recon, ransomware delivery. Often followed Emotet, provided a foothold for Ryuk or Conti. Decentralized infrastructure, encrypted comms, plugins for SMB spread and AD enumeration. Disrupted in 2022 after years of activity.</p></article>
    <article class="bad-family"><h4>Vidar</h4><p>Widely distributed infostealer harvesting credentials, browser data, cookies, cryptocurrency wallets, and more. Delivered via phishing, malvertising, fake installers. HTTP POST C2 with encrypted exfiltration. Customizable and available as malware-as-a-service. Often bundled with or mistaken for RedLine / Raccoon.</p></article>
    <article class="bad-family"><h4>WhisperGate</h4><p>Destructive malware attributed to Russian actors, deployed against Ukraine in 2022. Masquerades as ransomware but irreversibly corrupts the MBR and deletes system files. Two-stage: first corrupts the bootloader, second drops a wiper. No recovery mechanism, disruption, not finance. Echoed NotPetya tactics.</p></article>
  </div>

Affected web servers, routers, IoT. Exploits appeared within hours of disclosure. Drove broad review of UNIX-based software.</p></article>
    <article class="bad-term"><h4>Spectre / Meltdown</h4><p>Hardware vulnerabilities affecting modern microprocessors. Exploit speculative execution to leak memory across trust boundaries. Affect Intel, AMD, ARM chips. Required firmware and software mitigations. Paradigm shift in how hardware-level trust boundaries are viewed.</p></article>

    <article class="bad-term"><h4>Macro-based Execution</h4><p>Using macros embedded in Office documents or other files to execute malicious code once the file is opened.</p></article>
    <article class="bad-term"><h4>Process Doppelganging</h4><p>Exploiting Windows transaction mechanisms to execute malicious code under the guise of a legitimate process without modifying the original executable on disk.</p></article>
    <article class="bad-term bad-term--featured"><h4>Process Hollowing</h4><p>A legitimate process is created suspended, its memory replaced with malicious code, then resumed under the guise of a trusted process.</p></article>
    <article class="bad-term"><h4>Process Masquerading</h4><p>Altering the name or appearance of a malicious process to mimic legitimate system processes, evading detection.</p></article>
    <article class="bad-term"><h4>Reflective DLL Injection</h4><p>Stealthier DLL injection where the DLL loads itself into memory without touching disk, helping evade antivirus detection.</p></article>
    <article class="bad-term"><h4>Remote Execution</h4><p>Executing code or commands on a remote system, often through vulnerabilities or remote management tools.</p></article>
    <article class="bad-term"><h4>Sideloading</h4><p>Loading and executing a malicious DLL or module through a legitimate application to bypass security controls.</p></article>
    <article class="bad-term"><h4>Thread Injection</h4><p>Injecting malicious code into a running thread of another process for stealthy execution.</p></article>
  </div>

    <article class="bad-term"><h4>Data Breach</h4><p>An incident where an unauthorized party gains access to protected or sensitive data, often involving large-scale loss of personal or organizational information.</p></article>
    <article class="bad-term bad-term--featured"><h4>Data Exfiltration</h4><p>Deliberate and unauthorized transfer of data from a system or network to an external location.</p></article>
    <article class="bad-term"><h4>Data Exposure</h4><p>Data left accessible without proper controls, often due to misconfigurations like open cloud storage or unsecured APIs.</p></article>
    <article class="bad-term"><h4>Data Harvesting</h4><p>Automated or bulk collection of data via scrapers, malware, or scripts, often used for profiling, fraud, or resale.</p></article>
    <article class="bad-term"><h4>Data Leak</h4><p>Unintended or accidental release of sensitive data, often caused by human error, misconfigured systems, or negligence.</p></article>
    <article class="bad-term"><h4>Data Leakage Channels</h4><p>Stealthy exfiltration techniques such as covert DNS queries, encrypted uploads, or embedding in benign-looking traffic.</p></article>
    <article class="bad-term"><h4>Information Disclosure</h4><p>A system or application reveals internal details, sensitive metadata, or user data, often as part of a vulnerability or misconfiguration.</p></article>
    <article class="bad-term"><h4>Insider Data Theft</h4><p>Unauthorized access and removal of sensitive data by a trusted internal party with legitimate access.</p></article>
    <article class="bad-term"><h4>Sensitive Data in Transit</h4><p>Data intercepted while being transmitted across a network without proper encryption or integrity checks, vulnerable to MITM or sniffing.</p></article>
    <article class="bad-term"><h4>Shadow Data</h4><p>Sensitive or regulated data stored in unmanaged, forgotten, or unsanctioned locations, abandoned cloud buckets, rogue spreadsheets, old backups.</p></article>
    <article class="bad-term"><h4>Third-Party Data Exposure</h4><p>Compromise or exposure of sensitive data caused by a breach, misconfiguration, or negligence on the part of an external vendor or partner.</p></article>
    <article class="bad-term"><h4>Unstructured Data Exposure</h4><p>Leakage involving documents, logs, screenshots, audio, harder to classify or monitor using traditional DLP tools.</p></article>

    <article class="bad-term"><h4>File Extension Spoofing</h4><p>Files disguised with misleading extensions (e.g., <code>invoice.pdf.exe</code>) to trick users and bypass basic file-type filters.</p></article>

    <article class="bad-term"><h4>Low-And-Slow</h4><p>Performs actions gradually or in minimal increments to remain under detection thresholds.</p></article>
    <article class="bad-term"><h4>Masquerading</h4><p>Disguises a malicious process or file by renaming it or giving it the appearance of a trusted application.</p></article>
    <article class="bad-term"><h4>Memory Injection</h4><p>Injects code directly into memory rather than writing to disk, avoiding file-based detection.</p></article>
    <article class="bad-term"><h4>Parent PID Spoofing</h4><p>Spawns processes that appear to be launched by trusted executables (like <code>explorer.exe</code>), misleading analysts and EDR.</p></article>
    <article class="bad-term"><h4>Protocol Tunneling</h4><p>Encapsulates malicious traffic within legitimate protocols (HTTPS, DNS, ICMP) to bypass network detection.</p></article>
    <article class="bad-term"><h4>Signed Binary Proxy Execution</h4><p>Executes malicious code through trusted signed binaries (<code>rundll32</code>, <code>regsvr32</code>), exploiting inherent trust.</p></article>
    <article class="bad-term"><h4>Spoofed MACs</h4><p>Changes MAC addresses to impersonate other machines or confuse device-based monitoring.</p></article>
    <article class="bad-term"><h4>Subdomain Abuse</h4><p>Uses legitimate-looking subdomains (e.g., <code>cdn.dropbox.com.evil.com</code>) to trick filters and users.</p></article>
    <article class="bad-term bad-term--featured"><h4>Timestomping</h4><p>Alters file timestamps to make malicious activity appear older or less suspicious.</p></article>
    <article class="bad-term"><h4>Time-Based Evasion</h4><p>Schedules or delays actions to avoid time-sensitive monitoring tools or activate only during specific conditions.</p></article>
    <article class="bad-term"><h4>Toxic Access Pairing</h4><p>Combines multiple benign or low-privilege roles that together create excessive and dangerous access to sensitive resources.</p></article>
    <article class="bad-term"><h4>User-Agent Spoofing</h4><p>Alters HTTP headers to mimic trusted applications or browsers, blending into normal web traffic.</p></article>
    <article class="bad-term"><h4>Virtual Environment Awareness</h4><p>Malware detects sandboxes or VMs and refuses to execute, hiding true behavior from automated analysis.</p></article>
    <article class="bad-term"><h4>WMI Obfuscation</h4><p>Uses complex or hidden WMI commands to evade detection and gather data stealthily.</p></article>
