# C.A.T. Glossary

**C**ybersecurity **A**nalyst **T**oolbox, a categorized reference of the platforms and capabilities triage analysts work with day to day.

## Categories planned

- **Advisories / threat intelligence feeds**: sources of strategic, operational, and tactical intelligence.
- **Cloud and infrastructure monitoring**: visibility platforms for cloud workloads.
- **Data collection / logging / SIEM**: log aggregation and correlation platforms.
- **Endpoint detection and response (EDR)**: endpoint visibility and containment tools.
- **Forensics / digital evidence / mobile forensics**: investigation-grade data collection.
- **Identity and access management (IAM)**: identity directories and privilege management.
- **Intrusion detection / network security**: network-layer visibility and prevention.
- **Incident response / SOAR / automation**: orchestration and playbook execution.
- **Malware analysis / threat simulation / deception**: analysis and red-team tooling.
- **Network and application security testing**: vulnerability and exposure assessment.
- **Backup / data protection**: recovery and resilience tooling.
- **Software development / scripting**: analyst tooling and automation building blocks.
- **Security configuration / patch management**: hardening and remediation tools.
- **Physical security**: physical access and environmental monitoring.
