  <QuizItem
    prompt="An egress alert flags a workstation making sustained connections to an external host on port 443. What is the entity-type question to ask about this network identifier?"
    options={[
      { value: "a", label: "Whether the traffic really is the protocol 443 implies; SSH or DNS on 443 is the bypass." },
      { value: "b", label: "How rare port 443 is in the environment. Uncommon ports are the primary tunneling signal." },
      { value: "c", label: "Whether the destination IP has a clean reputation. A clean score clears the connection." },
      { value: "d", label: "None yet. Protocol analysis is deep-evidence work that belongs to Uncover, not Subject." },
    ]}
    answer="a"
    explanation="Port 443 is the most common port on the internet, so rarity carries no signal at all. The signal is protocol/port mismatch: traffic on 443 that is not actually TLS, or DNS on an arbitrary high port, is the classic bypass pattern, because attackers pick common ports precisely to blend in. Reputation helps but does not clear anything; a clean destination means only that it has not been caught yet. And conformance cuts one way only: most command-and-control (C2) traffic rides genuine TLS on 443, so conformant traffic moves the question to destination age, certificate, JA4 TLS client fingerprint and connection periodicity."

  <QuizItem
    prompt="In ASSURED's vocabulary, what separates insider risk from insider threat?"
    options={[
      { value: "a", label: "Nothing. The two terms are interchangeable vocabulary for any insider case." },
      { value: "b", label: "Risk is possible harm regardless of intent; threat is intentional, shown by evidence." },

      { value: "d", label: "Direction: insider risk comes from inside, insider threat from outside partners." },

    answer="b"
    explanation="The distinction is about intent. Most insider risk is unintentional (mistakes, workarounds, policy violations). Containment and escalation trigger on act, asset, and impact; intent is resolved in parallel."

    options={[
