ASSURED is learned by working cases, not by reading about them. The exercises are paper cases with answer keys; the labs run each phase on free public attack telemetry; the teaching guide and facilitator kit are for the person running the sessions.

A learner working alone can take the [exercises](/docs/exercises/) after each chapter quiz. A facilitator should read [Teaching ASSURED](/docs/teaching/) first: it routes each learner with a pre-assessment before any session starts.
