# U: Uncover - The Investigation

The Uncover phase is the fourth component of the ASSURED methodology, representing the core investigation process where analysts systematically collect and correlate telemetry from various sources to identify attack patterns and root causes. This phase transforms the structured approach established in previous phases into actionable intelligence through comprehensive evidence gathering and analysis.

## Overview

The Uncover phase is where the investigation comes to life through:
- Systematic evidence collection from multiple data sources
- Correlation and analysis of disparate information
- Threat intelligence integration and context
- Attack pattern recognition and mapping
- Root cause analysis and impact assessment

## Data Sources for Evidence Gathering

Effective investigation requires access to and analysis of multiple data sources to build a comprehensive picture of the security event.

### Endpoint Data Sources

**System Logs**
- Windows Event Logs (Security, System, Application)
- Linux/Unix system logs (syslog, auth.log, messages)
- Application-specific logs
- Service and daemon logs

**Process Information**
- Running processes and services
- Process creation and termination events
- Command line arguments and parameters
- Process relationships and parent-child hierarchies

**File System Data**
- File creation, modification, and access timestamps
- File integrity and hash values
- Registry modifications (Windows)
- Configuration file changes

**Network Activity**
- Network connections and listening ports
- DNS queries and responses
- Network traffic patterns
- Protocol-specific data

### Network Data Sources

**Network Monitoring**
- Packet capture data (PCAP files)
- NetFlow and sFlow data
- Network device logs (routers, switches, firewalls)
- Intrusion detection system alerts

**DNS and DHCP**
- DNS query logs and responses
- DHCP lease information
- Domain registration and WHOIS data
- Certificate transparency logs

**Email and Communication**
- Email headers and metadata
- Instant messaging logs
- VoIP and telephony records
- Collaboration platform data

### Identity and Access Data

**Authentication Logs**
- Active Directory logs
- Single sign-on (SSO) events
- Multi-factor authentication (MFA) logs
- Privileged access management (PAM) systems

**Authorization Events**
- Permission changes and grants
- Role modifications
- Access control list (ACL) changes
- Resource access patterns

**User Activity**
- Login and logout events
- Session management data
- Application usage patterns
- Behavioral analytics data

### Cloud and Infrastructure Data

**Cloud Service Logs**
- AWS CloudTrail, VPC Flow Logs
- Azure Activity Logs, Network Security Groups
- Google Cloud Audit Logs, VPC Flow Logs
- SaaS application logs

**Container and Orchestration**
- Kubernetes audit logs
- Docker container logs
- Container registry data
- Orchestration platform events

**Infrastructure Monitoring**
- Server performance metrics
- Application performance monitoring (APM)
- Database logs and queries
- Backup and recovery logs

### Threat Intelligence Types

- File hashes and signatures
- Email addresses and subjects
- Registry keys and file paths

**Tactics, Techniques, and Procedures (TTPs)**
- Attack methodologies
- Tool usage patterns
- Behavioral characteristics
- Campaign signatures

**Threat Actor Profiles**
- Attribution information
- Historical activities
- Motivations and objectives
- Capabilities and resources

**Campaign Intelligence**
- Related incidents and breaches
- Timeline and progression
- Geographic and industry targeting
- Success rates and impact

### Intelligence Integration

**Real-Time Correlation**
- Automated IOC matching
- Behavioral pattern recognition
- Campaign attribution
- Risk scoring and prioritization

**Historical Analysis**
- Past incident correlation
- Trend analysis and patterns
- Attribution consistency
- Evolution tracking

**Contextual Enrichment**
- Geographic and organizational context
- Industry-specific threats
- Regulatory and compliance implications
- Business impact assessment

## MITRE ATT&CK Framework

The MITRE ATT&CK framework provides a structured approach to understanding and mapping adversary behavior during investigations.

### Framework Structure

**Tactics**
- High-level adversary goals
- 14 main tactics (Initial Access, Execution, Persistence, etc.)
- Tactical objectives and outcomes
- Business impact categories

**Techniques**
- Specific methods used to achieve tactics
- Detailed implementation approaches
- Detection and mitigation guidance
- Real-world examples and case studies

**Sub-techniques**
- Granular variations of techniques
- Specific tool usage and methods
- Platform-specific implementations
- Detection and response procedures

### Investigation Application

**Technique Mapping**
- Map observed activities to ATT&CK techniques
- Identify attack progression and flow
- Understand adversary objectives
- Plan detection and response strategies

**Gap Analysis**
- Identify undetected techniques
- Assess security control effectiveness
- Plan security improvements
- Enhance detection capabilities

**Campaign Analysis**
- Track multi-stage attacks
- Understand attack chains
- Identify persistence mechanisms
- Plan comprehensive response

## Working Example: Uncover Phase

### Scenario: PowerShell Execution Investigation

**Initial Context:**
- Alert: Suspicious PowerShell execution on Workstation-IT-047
- User: jsmith@company.com (System Administrator)
- Time: 14:30 UTC
- Scope: Endpoint analysis, user behavior, network activity

**Evidence Collection:**

**Endpoint Data:**
- PowerShell execution logs showing base64-encoded commands
- Process creation events with command line arguments
- File system changes and registry modifications
- Network connections to external IP addresses

**Network Data:**
- DNS queries for suspicious domains
- Outbound connections to external servers
- Data transfer patterns and volumes
- Protocol analysis and payload examination

**Identity Data:**
- User authentication events and session data
- Privilege usage and escalation attempts
- Access to sensitive systems and data
- Behavioral pattern analysis

**Threat Intelligence:**
- IOC matching against known threat databases
- TTP analysis using MITRE ATT&CK framework
- Campaign attribution and context
- Risk assessment and impact evaluation

**Analysis Results:**
- Confirmed malicious PowerShell execution
- Data exfiltration attempt identified
- Lateral movement indicators found
- Attribution to known threat actor group

## Dynamic Loop: Scope Refinement

The Uncover phase operates in a dynamic feedback loop with the Scope phase, allowing for investigation scope refinement based on new findings.

### Scope Expansion Triggers

**New Evidence Discovery**
- Additional affected systems identified
- Broader attack campaign indicators
- New threat actor attribution
- Expanded data access patterns

**Escalation Criteria Met**
- High-severity findings
- Regulatory notification requirements
- Business impact escalation
- Management directive changes

### Scope Reduction Triggers

**False Positive Confirmation**
- Legitimate activity verification
- Misconfiguration identification
- Tool error confirmation
- User error validation

**Limited Impact Assessment**
- Isolated incident confirmation
- Minimal data exposure
- No lateral movement evidence
- Low business impact

## Transition to Risk Phase

After completing the Uncover phase, the investigation transitions to the **Risk** phase, where analysts will:

- Assess the risk and impact of discovered activities
- Quantify potential business impact
- Evaluate threat severity and likelihood
- Determine appropriate response priorities

The comprehensive evidence gathered in the Uncover phase provides the foundation for accurate risk assessment and response planning.

## Key Takeaways

1. **Comprehensive Evidence**: Multiple data sources provide complete investigation picture
2. **Threat Intelligence**: Context from threat intelligence enhances investigation effectiveness
3. **Structured Analysis**: MITRE ATT&CK framework provides systematic approach
4. **Dynamic Scope**: Investigation scope should adapt based on findings
5. **Documentation**: Thorough documentation ensures knowledge preservation

The Uncover phase represents the core investigative work of the ASSURED methodology, transforming structured preparation into actionable intelligence through systematic evidence gathering and analysis.
