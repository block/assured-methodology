# The sources that matter

<div class="src-grid">
  <div class="src"><h4>📋 Security event logs</h4><p>SIEM-collected events from across the environment. The first place most investigations start.</p></div>
  <div class="src"><h4>💻 EDR logs</h4><p>Process creation, command lines, network connections, file changes at the endpoint level.</p></div>
  <div class="src"><h4>🌐 Network traffic</h4><p>NetFlow, DNS queries, proxy logs, firewall logs. Where the perimeter sees what endpoints cannot.</p></div>
  <div class="src"><h4>🔑 Identity and access (IAM)</h4><p>Authentication events, SSO, role assumption, privilege grants.</p></div>
  <div class="src"><h4>☁️ Cloud activity logs</h4><p>AWS CloudTrail, Azure Activity, GCP audit. API calls and configuration changes.</p></div>
  <div class="src"><h4>🌐 Threat intelligence feeds</h4><p>IoCs and TTPs from external sources. Useful as enrichment, less useful as primary evidence.</p></div>
  <div class="src"><h4>🛡️ Vulnerability and patch logs</h4><p>What is exposed and what is patched. Context for prioritization.</p></div>
  <div class="src"><h4>📁 File integrity monitoring (FIM)</h4><p>Changes to critical files and configurations. Tampering signals.</p></div>
  <div class="src"><h4>📧 Email security logs</h4><p>Inbound/outbound message metadata, attachment scanning results, URL rewriting outcomes.</p></div>
  <div class="src"><h4>🗄️ Application and database logs</h4><p>What the app saw. Often the only place to find row-level access events.</p></div>
  <div class="src"><h4>📚 Configuration management / asset inventory</h4><p>What systems exist, who owns them, what they are for. Context for every other source.</p></div>
  <div class="src"><h4>🚫 Data loss prevention (DLP)</h4><p>What sensitive data moved where. Especially useful for exfiltration cases.</p></div>
  <div class="src"><h4>🍯 Deception / honeypot logs</h4><p>If anything touched the honeypot, that is high-confidence adversary behavior.</p></div>
  <div class="src"><h4>💾 Backup and snapshot metadata</h4><p>When systems were last clean. Important for response planning and timeline anchoring.</p></div>
  <div class="src"><h4>🏢 Physical security and access control</h4><p>Badge swipes, camera events. Especially relevant in insider cases.</p></div>
</div>

<KeyTakeaway>
The skill is not knowing every source by heart. The skill is asking "which source could answer this question?" and reaching for it deliberately. Most investigations need three to five sources in combination.
</KeyTakeaway>
