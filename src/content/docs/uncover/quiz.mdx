<Quiz title="Uncover chapter quiz">

  <QuizItem
    prompt="A threat intel feed says a particular domain is associated with a known campaign. The analyst sees the same domain in firewall logs from one host. What is the right next step?"
    options={[
      { value: "block", label: "Block the domain immediately. Intel is intel." },
      { value: "validate", label: "Use the intel as a hypothesis. Validate by checking what process initiated the connection and whether the connection matches the campaign's broader pattern." },
      { value: "ignore", label: "Ignore the intel. Domains change all the time." },
      { value: "share", label: "Share the intel with the team without action." },
    ]}
    answer="validate"
    explanation="Threat intelligence is most useful as a hypothesis. The matched domain is a starting point, not a verdict. Validate against the actual telemetry (which process, which user, which pattern) before acting."
  />

  <QuizItem
    prompt="Which level of MITRE ATT&CK changes most often?"
    options={[
      { value: "tactics", label: "Tactics" },
      { value: "techniques", label: "Techniques" },
      { value: "procedures", label: "Procedures" },
      { value: "all-same", label: "All change at the same rate." },
    ]}
    answer="procedures"
    explanation="Procedures (specific implementations) change rapidly as adversaries adapt their tooling. Techniques (the methods) change more slowly. Tactics (the goals) are nearly stable over years. This is why TTP-based hunting beats indicator matching for durability."
  />

  <QuizItem
    prompt="An investigation needs to know if a file ever ran on an endpoint. Which data source answers this most directly?"
    options={[
      { value: "siem", label: "SIEM" },
      { value: "edr", label: "EDR" },
      { value: "fim", label: "FIM" },
      { value: "network", label: "Network analysis" },
    ]}
    answer="edr"
    explanation="EDR captures process creation events that show whether a file was executed. FIM tells you the file exists or was modified, but not whether it ran. SIEM aggregates events from multiple sources; EDR is the source that answers execution directly."
  />

  <QuizItem
    prompt="The Uncover narrative concludes with a chain of MITRE techniques. Why is the chain more useful than free-form prose?"
    options={[
      { value: "shorter", label: "It is shorter." },
      { value: "portable", label: "It is a shared vocabulary the IR team, detection engineers, and trend analysts all recognize. The chain travels better than prose." },
      { value: "required", label: "It is required for compliance." },
      { value: "easier", label: "It is easier to write." },
    ]}
    answer="portable"
    explanation="ATT&CK turns analyst observations into a portable artifact. The same chain of techniques is meaningful to the IR responder, the detection engineer who decides what to tune, and the leader who wants to see threat trends over time."
  />

</Quiz>
