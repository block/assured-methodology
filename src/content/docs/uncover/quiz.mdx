<Quiz title="Uncover chapter quiz">

  <QuizItem
    prompt="A threat intel feed says a particular domain is associated with a known campaign. The analyst sees the same domain in firewall logs from one host. What is the right next step?"
    options={[
      { value: "block", label: "Block the domain immediately. Intel is intel." },
      { value: "validate", label: "Use the intel as a hypothesis. Validate by checking what process initiated the connection and whether the connection matches the campaign's broader pattern." },
      { value: "ignore", label: "Ignore the intel. Domains change all the time." },
      { value: "share", label: "Share the intel with the team without action." },
    ]}
    answer="validate"
    explanation="Threat intelligence is most useful as a hypothesis. The matched domain is a starting point, not a verdict. Validate against the actual telemetry (which process, which user, which pattern) before acting."
  />

  <QuizItem
    prompt="Which level of MITRE ATT&CK changes most often?"
    options={[
      { value: "tactics", label: "Tactics" },
      { value: "techniques", label: "Techniques" },
      { value: "procedures", label: "Procedures" },
      { value: "all-same", label: "All change at the same rate." },
    ]}
    answer="procedures"
    explanation="Procedures (specific implementations) change rapidly as adversaries adapt their tooling. Techniques (the methods) change more slowly. Tactics (the goals) are nearly stable over years. This is why TTP-based hunting beats indicator matching for durability."
  />

  <QuizItem
    prompt="An investigation needs to know if a file ever ran on an endpoint. Which data source answers this most directly?"
    options={[
      { value: "siem", label: "SIEM" },
      { value: "edr", label: "EDR" },
      { value: "fim", label: "FIM" },
      { value: "network", label: "Network analysis" },
    ]}
    answer="edr"
    explanation="EDR captures process creation events that show whether a file was executed. FIM tells you the file exists or was modified, but not whether it ran. SIEM aggregates events from multiple sources; EDR is the source that answers execution directly."
  />

  <QuizItem
    prompt="The Uncover narrative concludes with a chain of MITRE techniques. Why is the chain more useful than free-form prose?"
    options={[
      { value: "shorter", label: "It is shorter." },
      { value: "portable", label: "It is a shared vocabulary the IR team, detection engineers, and trend analysts all recognize. The chain travels better than prose." },
      { value: "required", label: "It is required for compliance." },
      { value: "easier", label: "It is easier to write." },
    ]}
    answer="portable"
    explanation="ATT&CK turns analyst observations into a portable artifact. The same chain of techniques is meaningful to the IR responder, the detection engineer who decides what to tune, and the leader who wants to see threat trends over time."
  />

  <QuizItem
    prompt="An analyst is investigating a possible compromise on a macOS developer workstation. The user's role legitimately involves scripting, IDE plugin processes, and encrypted outbound traffic. What does the methodology require Uncover to produce if the evidence supports a false-positive verdict?"
    options={[
      { value: "dismiss", label: "Dismiss the alert. Move on." },
      { value: "evidenced", label: "Document the verdict with the same rigor as a positive finding: chain of evidence, confidence levels, explicit coverage gaps, ATT&CK mapping (or explicit absence), and detection-engineering feedback." },
      { value: "shorten", label: "Write 'false-positive' in the case notes and close." },
      { value: "escalate", label: "Escalate anyway since the activity looks suspicious." },
    ]}
    answer="evidenced"
    explanation="A false-positive verdict that meets the methodology's standard is not dismissed. It is documented, evidenced, and bounded. That documentation is what lets the case re-open with full context if new signals appear, and what produces the detection-engineering feedback that prevents the same alert from firing repeatedly."
  />

  <QuizItem
    prompt="Risk receives an Uncover handoff. Which of these decisions is Risk authorized to make?"
    options={[
      { value: "isolate", label: "Isolate the host." },
      { value: "notify", label: "Notify regulators." },
      { value: "binary", label: "Close the event with confidence, or push back to Scope to expand the investigation. Risk's binary decision drives what happens next; it does not perform containment or notification itself." },
      { value: "tune", label: "Tune the detection rule that fired." },
    ]}
    answer="binary"
    explanation="Risk is the analytical checkpoint, not the response phase. Its job is to evaluate whether Uncover's evidence is sufficient to close the case or whether the investigation needs to expand. Containment, notification, and detection tuning happen in later phases (Escalation, Documentation) once Risk's verdict supports them."
    hint="Risk is not response."
  />

  <QuizItem
    prompt="During Uncover, a TLS certificate associated with a known C2 campaign appears in proxy logs from one internal host. The threat-intel feed labels it medium confidence, 30 days old. What is the right next move?"
    options={[
      { value: "block", label: "Block the certificate's domain across the perimeter and close the case." },
      { value: "validate", label: "Use the match as a hypothesis. Validate by examining what process initiated the connection, what came before and after, and whether the broader campaign's TTPs are present. Confidence stays medium until evidence in the environment corroborates the intel." },
      { value: "low-conf", label: "Ignore. Medium confidence is not actionable." },
      { value: "expand", label: "Immediately expand scope to every host that has spoken to that hosting provider." },
    ]}
    answer="validate"
    explanation="The intel match raises a hypothesis at medium confidence. The methodology says validate against the environment's own telemetry (which process, which user, what came next) before acting. Validation may promote the case to high confidence, demote it to false-positive, or leave it ambiguous and shape what Risk will decide. The match alone is not the verdict."
  />

  <QuizItem
    prompt="The five intelligence-use patterns Uncover relies on most are indicator matching, attribution, TTP hunting, automated enrichment, and dark-web monitoring. Which one is most durable against an adversary that changes tools every campaign?"
    options={[
      { value: "indicator", label: "Indicator matching." },
      { value: "attribution", label: "Attribution to a named group." },
      { value: "ttp", label: "TTP-based hunting, because techniques change far less often than the specific tools or infrastructure that implement them." },
      { value: "darkweb", label: "Dark-web monitoring." },
    ]}
    answer="ttp"
    explanation="Indicators (hashes, domains, IPs) change every campaign and can be modified in minutes. Procedures (specific tool implementations) change between campaigns. Techniques (the underlying methods) change in years. TTP-based hunting builds detection on the most durable layer, which is why it outperforms indicator matching against sophisticated adversaries."
  />

</Quiz>
