# The tool families

<div class="tool-grid">
  <div class="tool"><h4>🔎 SIEM</h4><p>Centralized event search and correlation. Splunk, QRadar, Sentinel, Chronicle, Elastic. The investigation's primary query window.</p></div>
  <div class="tool"><h4>💻 EDR</h4><p>Endpoint detection and response. CrowdStrike, SentinelOne, Defender XDR. Process trees, command lines, on-host containment.</p></div>
  <div class="tool"><h4>🌐 Network analysis</h4><p>Zeek, Suricata, Corelight, Arkime. Wire-level observation. Catches what endpoint telemetry cannot.</p></div>
  <div class="tool"><h4>🧠 Threat intelligence</h4><p>Mandiant, CrowdStrike, Recorded Future, MISP. Enrichment and hypothesis generation.</p></div>
  <div class="tool"><h4>🍯 Deception</h4><p>Honeypots, decoy accounts, fake data. Anything that touches deception is, by definition, suspicious.</p></div>
  <div class="tool"><h4>🔬 Digital forensics</h4><p>FTK, EnCase, Volatility, Sysinternals. Deep host analysis for confirmed cases.</p></div>
  <div class="tool"><h4>🛡️ Vulnerability scanners</h4><p>Qualys, Tenable, Rapid7. What is exposed and what is patched.</p></div>
  <div class="tool"><h4>🤖 SOAR</h4><p>Splunk Phantom, Cortex XSOAR, Sentinel Playbooks. Playbook execution and triage automation.</p></div>
  <div class="tool"><h4>☁️ CSPM</h4><p>Cloud security posture management. Wiz, Lacework, Prisma. Cloud misconfiguration and exposure visibility.</p></div>
  <div class="tool"><h4>🏞️ Data lakes</h4><p>Snowflake, BigQuery, Databricks. When SIEM retention is too short or queries are too complex.</p></div>
</div>

# Choosing the right tool

The pattern is always the same:

- Start with the question.
- Identify which tool category can answer it.
- If the answer requires multiple sources, plan the query order to minimize re-work.
- Document what tools were used and what queries were run. The audit trail matters.

<KeyTakeaway>
Tools serve the question, not the other way around. Strong analysts learn the question-to-tool mapping deliberately and reach for the right one at the right step. Weak analysts run the same SIEM query against every alert and hope.
</KeyTakeaway>
